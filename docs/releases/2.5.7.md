Open several textures in your editor at once, and fixes in the texture manager.

## New

- **Open in editor for several textures.** Select textures with Ctrl+click, Shift+click, a dragged box or Ctrl+A, then right-click one of them or use the details panel. Each one opens in your default `.dds` editor. Encrypted `resorep1` textures are skipped, and ReResorep asks first before opening more than 10.
- If no program is set up to open `.dds` files, ReResorep now says so instead of doing nothing.

## Fixes

- **Go to mod**, in a dump's details, switches to the Mods tab and selects the mod again. Before, it only cleared the selection. The same goes for **Show** in the Similar textures window, and for the jump to a mod you just imported.
- A label typed in the details panel is no longer lost when you click another texture, switch tabs or close ReResorep before pressing Enter. Pressing Esc no longer reports a label as saved or removed.
- Importing many `.dds` files at once no longer freezes the window while the folders are rescanned after every file.
- Long texture lists sort and search with less work each frame.
- Exporting labels reports a failed write, for example to a full disk, and importing labels reports a file that can't be read.
- The same game can no longer be added twice through a differently spelled path.
- Deleting a mod only resets the sidebar to All textures when you were viewing that mod.

The first start after updating reads each texture's header once more, to note which textures are encrypted. After that it is cached again.

The proxy (`proxy/d3d11.dll`) is the same 2.5.0 file as in earlier releases (SHA-256 `f7f8358ae96a1a3d87a6853594c1bab27098dbcc9966a4719ba49b76773a1eac`), so games with the 2.5.0 proxy need no update.
