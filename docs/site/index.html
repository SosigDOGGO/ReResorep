Swap Siege textures by hash

ReResorep is a native rewrite of Resorep, the DirectX 11 texture replacer. One small app finds, sorts and tints textures; a d3d11.dll proxy puts your replacements into the game. Your existing Resorep packs keep working.

Download ReResorep 2.5.5 How to install

Windows x64. No Java, runtime or VC++ redistributable needed.

Before you start

DirectX 11 only
Siege from Y10S1 on, Siege X included, runs on DirectX 12 only, so the proxy works with older builds that still have DirectX 11. DirectX 12 support isn't built yet.
Offline setups
Online Siege runs BattlEye, and a replacement d3d11.dll in the game folder is the kind of thing it can flag. Use ReResorep for offline and modded setups.

Install ReResorep

ReResorep has no installer. It's a folder you extract once and keep. Most install problems come from running it straight out of the zip, so take a minute over steps 2 and 3.

  1. Download the zip

    On the latest release, open Assets and download the file ending in -win64.zip. Source code (zip) is the source code and has no app in it.

  2. Extract all of it

    Right-click the zip and choose Extract All…. Don't open the zip and double-click ReResorep.exe inside it. Windows then runs the exe from a temporary folder without its proxy folder, and your settings and mods get deleted along with that temporary folder.

  3. Give it its own folder

    Put the extracted folder somewhere that's easy to find, like C:\ReResorep or your Documents. Not inside the game folder, and not in Program Files. Keep ReResorep.exe and proxy together, and don't move the exe out of the folder.

  4. Add your game

    Run ReResorep.exe. In the Games tab choose Add game…, pick RainbowSix.exe and press Install. Then press Start or start the game the way you always do. A d3d11.dll already in the game folder, like ReShade, is kept and still loads.

What the folder should look like

C:\ReResorep\
  ReResorep.exe
  proxy\
    d3d11.dll    goes to the game
  README.txt
  modded\       your mods
  original\     dumped textures
  reresorep.ini settings

modded, original and reresorep.ini appear the first time you run ReResorep. Everything it makes stays in this folder. To move it, close ReResorep, move the whole folder, then press Reinstall for each game on the Games tab so the game knows where your mods are now.

Finding RainbowSix.exe

  • Steam: right-click Rainbow Six Siege in your library, then Manage → Browse local files.
  • Ubisoft Connect: open the game, then Properties, and under Local files choose Open folder.
  • Pick RainbowSix.exe. RainbowSix_BE.exe is the BattlEye launcher and RainbowSix_Vulkan.exe doesn't use DirectX 11, so neither loads the proxy.

"Windows protected your PC"? Windows SmartScreen can show this for apps that aren't downloaded by many people yet. Choose More info, then Run anyway. Only do this for a copy you got from the GitHub releases page.

Don't copy d3d11.dll into the game folder by hand. Install also writes a dllsettings.ini next to it that tells the proxy where your mods are. Without it, the proxy looks in the game folder instead and finds none of them.

Installing mods

Don't unzip mods. Give ReResorep the .zip and it unpacks the textures into the right folder itself, checks every file and keeps the mod's categories.

  1. A mod in a .zip

    Drag the .zip onto the ReResorep window, or use Import mod… in the Mods tab. You can rename the mod before it's imported.

  2. Single .dds textures

    Drag them onto the window, or use Import .dds…. Files that aren't named after a hash get asked which texture they replace.

  3. A .rar, .7z or an unpacked folder

    Extract it somewhere temporary first. Then in the Mods tab press Open folder and copy the mod's folder into the folder that opens.

Mods go here

The modded folder inside your ReResorep folder, for example C:\ReResorep\modded\Ash Elite\. A folder per mod is fine, and so is any depth of folders inside it.

Open folder in the Mods tab always opens the right one, also when you changed it in Settings or picked a game with its own folders at the top.

Not in any of these

  • The game folder, next to RainbowSix.exe
  • original: that's where dumps go, and nothing in it is loaded
  • proxy, or loose next to ReResorep.exe
  • Downloads, the Desktop, or anywhere else outside modded
  • Still zipped inside modded: only .dds files are read

Textures have to keep their names: <hash>.dds or <hash>~name.dds, like 2233445566.dds. A renamed file is skipped. Changes reach a running game within about a second, but textures it has already loaded only change when it loads them again, for example on the next map.

What it looks like

Make your own mods

  1. Find the textures you want

    Turn on Mod creator mode and Dump textures in Settings, then play. The Dumps tab fills with the game's textures, each named by its hash.

  2. Replace them

    Select a dump and choose Replace with .dds…, or drag .dds files onto the window. Changes reach a running game within about a second.

  3. Share them

    Right-click your mod in the Mods sidebar and choose Export…. Others install the .zip by dropping it onto their ReResorep window.

Need an editor? We recommend GIMP. It's free, and it opens dumped .dds textures and exports your edits back to .dds.

Just playing? Turn on Low impact mode. The proxy then only replaces textures and reads your mods once when the game starts.

What it does

Mods and categories

Each folder in your modded folder is a mod, and each folder inside it is a category. Turn any texture, category or whole mod on or off. Files are never moved, so turning something back on restores it exactly. 

modded/
  12345.dds      loose texture
  Ash Elite/     mod
    Uniform/     category
      2233445566.dds
    Weapons/     category
      3344556677.dds
Big dump folders, sorted
Sort by hash, name, date, size, resolution or format. Name any hash with your own label. Hide normal maps and grayscale masks, which are detected in the background.
Find its normal map
Right-click a texture to find its normal map or similar textures, ranked by matching detail, size and when they were dumped.
Share mods as a zip
Export a mod with its categories, on/off choices and labels. Importing only ever unpacks .dds files into your modded folder, and checks every file.
Several Siege builds
Builds are told apart by the exe's SHA-256. Give a build its own folders, or mark a mod as made for one build so the others skip it.
Damaged copies won't run
The app and the proxy check their own checksum when they start. A broken proxy still lets the game start but changes nothing, and Repair installs a fresh copy.
Nothing phones home
No analytics and no update check. The original's Google Analytics and version ping are gone.

If something's wrong

"proxy\d3d11.dll is missing next to ReResorep.exe"
ReResorep was started from inside the zip, or ReResorep.exe was moved out of its folder. Extract the whole zip (see Install) and run the exe from the extracted folder.
My mods and settings disappeared
If ReResorep was run from inside the zip, it saved everything in a temporary folder that Windows has since cleaned up. Extract the zip, run it from there and import your mods again.
Install says "permission denied"
The game is in a folder Windows protects, such as Program Files. Right-click ReResorep.exe, choose Run as administrator, press Install, then close it and run it normally from then on.
The game starts, but nothing changes
Check, in this order: the game is a DirectX 11 build (Y10S1 and later are DirectX 12 only); you added RainbowSix.exe; the Games tab says the proxy is installed; the mod is in modded and its checkbox is on; and in shared folders, the mod isn't marked Made for another build.
"Proxy modified" or "damaged"
The d3d11.dll in the game folder was damaged or changed by something else. Press Repair on the Games tab. If ReResorep.exe itself won't start, download ReResorep again.
Removing ReResorep
Press Uninstall for each game on the Games tab. That puts back any d3d11.dll the game had before. Then delete the ReResorep folder.

Compared to Resorep 1.7

Mods made for Resorep work unchanged: <hash>.dds, <hash>~name.dds, encrypted resorep1 packs and the ±2 hash tolerance. What's different is underneath.
